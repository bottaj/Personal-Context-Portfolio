# Changelog – Personal Context Portfolio

All notable changes to this Personal Context Portfolio are documented here.
This file exists to provide transparency and version awareness when the context
is shared with AI agents over time.

The format follows a lightweight semantic versioning approach:
- MAJOR: Significant role or scope changes
- MINOR: Preference, tooling, or goal updates
- PATCH: Wording, clarity, or formatting improvements
